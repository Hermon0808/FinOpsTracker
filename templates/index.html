About the Project

FinOpsTracker is a full-fledged DevOps project that automates the deployment of an Expense Tracker application. It integrates tools like Docker, Terraform, Kubernetes, Ansible, and GitHub Actions for CI/CD.

The app helps users track their daily expenses, categorize spending, and gain insights through simple visualizations—all hosted on the cloud and deployed using Infrastructure as Code.

Deployed with Automation on Azure Kubernetes Service using Terraform & GitHub Actions

App Features

💸 Expense Tracking

Log, edit, and categorize your daily expenses with ease.

📊 Data Visualization

View monthly spending breakdowns via charts and analytics.

☁️ Cloud Deployment

Automated CI/CD pipelines deploy the app to Azure via GitHub Actions.

🐳 Dockerized App

Lightweight, portable containerization ensures consistency across environments.

⚙️ IaC with Terraform

Provisioning of AKS and cloud resources using Infrastructure as Code.

🤖 Ansible Automation

Automated deployment and configuration management via playbooks.
